### Business Context

Account managers need a consistent way to identify customers who receive priority service. An optional Gold, Silver, or Bronze tier on Account lets the team quickly recognize that classification without changing existing service processes.

### Scope

* In scope:
    * Add an optional restricted Customer Tier picklist to Account with Gold, Silver, and Bronze.
    * Display the field on every current Account page layout and provide editor and viewer field access through dedicated permission sets.
* Out of scope:
    * Automatic tier assignment or service changes based on tier.
    * Additional values, defaults, requiredness, integrations, or changes to Account sharing.

### Acceptance Criteria

* AC1: Given an account manager has edit access to an Account, when they set Customer Tier to Gold, Silver, or Bronze and save, then the selected value is accepted and remains on the Account.
* AC2: Given an account manager creates or edits an Account, when they leave Customer Tier blank and save, then the Account saves successfully with Customer Tier blank.
* AC3: Given an Account is displayed on any current Account page layout and the user has read access to Customer Tier, when they open the Account record page, then Customer Tier is visible.

### Technical Notes

Add a restricted optional Account picklist, update all source-controlled Account layouts, and grant field access using dedicated permission sets. Account sharing and object CRUD remain unchanged; Salesforce field-level security controls whether users can read or edit the field. No Apex, Flow, LWC, or integration changes are needed.

### Risks

* Intended users may not see the field without field read access → assign the new viewer or editor permission set to all intended readers.
* The exact user audience for each permission set is unspecified → confirm assignments with the release owner before production rollout.

### Open Questions

* OQ1: Which existing users should receive edit and read access to Customer Tier?
    * Recommended answer: assign the editor permission set to account managers and the read-only viewer permission set to the broader intended Account team; confirm actual assignments with the release owner because user-role mappings are not present in source.
* OQ2: Should Customer Tier be separate from the existing Account.CustomerPriority__c field shown on the current layouts?
    * Recommended answer: keep Customer Tier separate and leave CustomerPriority__c unchanged because its definition and values are not in source and the story explicitly specifies Gold, Silver, and Bronze.
